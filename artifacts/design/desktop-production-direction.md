## Four meaningful depths

Latest refinement: preserve the four assemblies and stage truth; shorten the
scroll track to 210vh, enlarge the drawing and pair it with an adjacent caption.
A camera fitted to the assemblies' translated bounds reinforces depth without
cropping exposed parts or capturing the wheel. Mount-aligned guides explain
where the raised control assembly seats. Separation occupies more of each stage.
Give the hero more vertical space while retaining 76px type. Share the canonical
Relevo wordmark across header/footer and use brand-first browser titles. Keep
active random pixels in the hero only; remove the separate bottom strip,
pointer-driven displacement and fluid waves. Docs tracks
the visible section; Flow includes explicit submission and recovery states.

Native scroll reveals Coordinator (intake/control), Workers (carriages and rail),
Recovery (retry mechanism beneath them), then Saved record (storage foundation).
Every depth changes geometry, current assembly emphasis, stage indicator, heading
and short explanation. Keep the task cartridge connected to storage throughout.
Use four distinct physical assemblies, not an unexplained lifted lid or generic
PCB slabs. Readable holds, symmetric reverse scrolling, no wheel interception or
scroll snapping. Reduced motion: separated still and all four explanations.

## Type and motion

Hero 76px; other page headlines 68px; section headings40px; supporting titles
24–28px; body18–20px; navigation/buttons16–17px. Keep code readable. Scale spacing
with type; preserve the accepted section order and essential evidence content.

Cierto's public desktop patterns and the 21st.dev/Magic UI Interactive Hover
Button informed fill sweeps and coordinated arrows. Use local CSS and installed
Motion14.4.0, not new UI frameworks. Button feedback150–300ms; larger changes
300–500ms; no bounce by default. Keep selected states distinct from hover. Cards
that do not navigate keep normal cursors. One short hero entrance, selective
viewport-triggered content entrances, reversible FAQ and Engine state transitions.
Home content groups reveal once on entry; backgrounds keep their normal flow,
keyboard focus reveals immediately and reduced motion shows all content. The
hero-only Canvas regenerates occupancy and brightness on a fixed grid, with no
wave-shaped displacement or pointer disturbance. It caps DPR/frame rate,
suspends offscreen/hidden and provides a reduced-motion still.
