## Six-block direction contract

1. Audience/job: curious newcomers understand saved background work and recovery;
   developers can inspect recorded facts and measurements on demand.
2. Outcome: a complete clickable desktop preview of all six routes before the
   final website build; keep the existing source/layout intact for comparison.
3. Composition: broad typographic Home hero → edge-to-edge pixels → centered
   Assembly model chapter → familiar use case/recovery → FAQ → Docs → grouped
   footer. Engine inherits the Museum workspace. Supporting pages inherit tokens.
4. Material/motion: original filled, shaded Anatomy solids; native scroll drives
   separation. No hero widget, repeated model, endless ambient loop or global
   pause button. Motion coordinates FAQ and focus/hover feedback.
5. Truth: actual committed evidence, stable friendly worker aliases, exact fields
   and untimed test interventions in Technical details; no invented crash time,
   live integration, customer, throughput, exactly-once or completion guarantee.
6. Boundaries: local React/JavaScript/Vite prototype. Desktop only. No tablet/
   phone work or checks, backend changes, publication or final-site completion.
   Stop after opening the verified demo for feedback.
